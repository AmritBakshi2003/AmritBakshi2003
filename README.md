### 👤 About Me
I'm **Amrit Bakshi**, a Computer Science undergraduate from India transitioning from full-stack development toward Data Analytics and Data Science. 

I enjoy exploring complex datasets, uncovering valuable patterns, and building practical utilities around what I learn. My comprehensive software development background allows me to build end-to-end data tools, dynamic web apps, and performance-tuned desktop utilities.

* 🔍 **Current Focus:** Data Analytics, Python, SQL, Excel, and Power BI
* 🛠️ **Building on the Side:** Interactive web applications and desktop utilities
* 💡 **Interests:** Business intelligence, strategic data storytelling, and user-centric software
* 🤝 **Open to:** Data Analyst roles, analytics internship opportunities, and collaborative open-source builds
